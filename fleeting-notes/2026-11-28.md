# Try the OpenCode Rune dev build

On 2026-11-27, OpenCode announced an early `dev` build of **OpenCode Rune**, the next version of its desktop app, rewritten from scratch in Rust on the native Rune framework. It does not use Electron, making it much snappier. Native builds are available for macOS, Windows, and Linux; Linux offers AppImage, DEB, and RPM packages and updates manually.

To try: install the Linux x64 dev build on Ubuntu.

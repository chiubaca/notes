# Effect UI

Effect UI is the Effect team’s public-preview frontend library and successor to Foldkit 0.x. Each component is its own Elm-style model/update/view program with typed messages and Effect-based side effects. It adds localized updates, Providers, cached queries, host-agnostic rendering (HTML/server/test/OpenTUI), 41 headless accessible components, DevTools time travel, and Story/Scene/Play tests. It is not on npm yet; use snapshot builds. Interesting for new Effect-based apps, but not a drop-in migration for existing Astro/React sites.

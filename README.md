# 📓 Notes 

Notes for everything; thoughts, musings, TILs , blogs.

## Validation

Run `node scripts/validate-frontmatter.mjs` to validate note frontmatter. Enable the tracked pre-commit hook once per clone with `git config core.hooksPath .githooks`.

I'm using the [zettelkasten](permanent-notes/zettelkasten.md) method or organise my notes.
